# Fuentes de datos y licencias

El código de este repositorio es MIT (ver `LICENSE`). Los datos que sirve la API se calculan en los
notebooks de Colab del equipo a partir de datos abiertos; cada fuente conserva su licencia.

La lista completa, con enlaces y citas, está en el documento del equipo «Bibliografía y fuentes de
datos — Análogos terrestres Luna y Marte». Resumen de las fuentes principales:

| Capa | Fuente | Licencia / condiciones |
|---|---|---|
| Topografía de la Tierra | Copernicus DEM GLO-30 (ESA) | Licencia Copernicus DEM: uso libre con atribución |
| Topografía Luna / Marte | LRO LOLA, MGS MOLA (NASA PDS) | Dominio público (NASA) |
| Clima de la Tierra | MODIS Aqua MYD11C3 v061 (NASA LP DAAC); MERRA-2 (NASA GMAO) | Datos abiertos NASA |
| Clima de la Luna | LRO Diviner (NASA PDS) | Dominio público (NASA) |
| Clima de Marte | MACDA (Mars Analysis Correction Data Assimilation) | Datos abiertos con cita |
| Geología de la Tierra | GLiM (Global Lithological Map) | CC BY (cita requerida) |
| Cuevas de la Luna | LROC Lunar Pit Atlas (ASU / NASA) | Datos abiertos con cita |
| Cuevas de Marte | Mars Global Cave Candidate Catalog (USGS) | Dominio público (USGS) |
| Cuevas de la Tierra | Pyroduct (Zenodo), USGS HVO, literatura citada en la ficha | Según cada registro |
| Anortosita | Ficha de análogos (ESA, CSA, NASA JSC y otras fuentes citadas) | Según cada fuente |

Antes de la entrega hay que revisar esta tabla contra la bibliografía (tarea «Citas y licencias en
la entrega» del GitHub Project).
